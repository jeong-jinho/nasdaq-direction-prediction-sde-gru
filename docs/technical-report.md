# 기술 보고서 — 머신러닝 기법을 이용한 금융시장 모델링


## 초록

본 연구는 머신러닝 기법을 활용하여 금융시장의 가격 변동 패턴을 예측하고, 변동성 급등 구간을 효과적으로 탐지하는 모델을 구축하는 것을 목적으로 하였다. 최근 금융시장은 고빈도 거래, 글로벌 거시 변수, 투자 심리 등 다양한 요인이 복합적으로 작용하며 비선형적 움직임을 보이기 때문에, 전통적 통계 기반 예측 기법만으로는 정확한 시장 전망에 한계가 존재한다. 이에 본 연구에서는 2014년부터 2024년까지의 주요 주가지수 및 개별 종목 데이터를 수집하여 전처리한 뒤, 시계열 기반 딥러닝 모델(GRU)과 확률적 생성 기반 모델(SDE)을 구축하였다.

**주요어**: 금융시장, 머신러닝, 시계열 예측, SDE, GRU, 변동성 예측

---

## 1. 데이터 및 전처리

- 분석 대상: 나스닥 지수(시가, 거래량, 일간 변동률), 달러인덱스(DXY), 미국 국채금리 — 약 10년(2014–2024)의 일별 시계열
- 세 데이터셋을 날짜 기준으로 병합, 공통 관측 기간만 사용
- 결측치가 있는 행은 제거해 시계열 연속성 확보
- 입력 변수(4개, 일간 변화율·차분): 지수 시가 수익률, 거래량 변화율, 변동률 지표, 국채금리 변화분
- 달러인덱스는 초기 실험 변수로 포함해 테스트했으나, 성능 개선이 거의 없으면서 연산 부담만 늘어 최종 파이프라인에서는 제외
- 전 변수 표준화(평균 0, 분산 1)
- **분할**: 시간 종속성을 고려해 순차 분할 — 마지막 30일을 테스트 구간, 검증 비율 0.1. 테스트 구간에 대해 하루씩 순차 예측(rolling forecast)

---

## 2. 모델링

### 2.1 SDE (확률미분방정식 기반 점수추정 모델)

| 항목 | 값 |
| --- | --- |
| 입력 차원 | 4 (국채금리 포함, 달러인덱스는 연산 효율성을 위해 최종 제외) |
| 구조 | Softplus MLP, 은닉층 32 |
| 확산 시간 매개변수 | 0.01 ~ 0.99 (균등 구간) |
| 손실 함수 | Gauss–Hermite 수치적분 기반 밀도 근사 |
| 최적화 | Adam, lr=0.001, weight decay=1e-4 |
| 안정화 | Gradient clipping, Early Stopping (patience 100 epoch) |
| 예측 방식 | 학습 분포에서 다수의 모의 경로 생성 → 상승 종가 비율 50% 이상이면 "상승" |

### 2.2 GRU (순환신경망)

| 항목 | 값 |
| --- | --- |
| 입력 특징 | 시가 변화율, 거래량 변화율, 일일 변동률, 국채금리 변화율 (4개) |
| 시퀀스 길이 | 20일 |
| 구조 | 2층 GRU(은닉 64) + Dropout + FC layer |
| 출력 | 다음날 시가 변화율 |
| 최적화 | Adam, lr=0.001, weight decay 적용 |
| 안정화 | Gradient clipping, Early Stopping (patience 50 epoch) |
| 예측 방식 | 직전 20일 시퀀스 → 다음날 예측 → 예측값을 시퀀스에 반영해 30일 롤링 예측 |

전처리 과정에서 결측값 처리, 문자열→숫자 변환, 이상치 보정을 거쳤고 주말(비거래일)은 제외했다.

## 3. 결과

### 3.1 SDE — 기본 모델 (국채금리·달러인덱스 미포함)

30일 롤링 예측 결과, **최종 예측 정확도 46.67%**. 전체적으로 상승을 과대 예측하는 경향이 나타났고, 단기 변동성이 높은 시점에서 실제 방향과 불일치가 반복됨 — 입력 변수 제한으로 시장의 복잡한 변동성 구조를 충분히 학습하지 못한 것으로 판단.

> 전체 데이터: [`results/sde_baseline_predictions.csv`](../results/sde_baseline_predictions.csv)

### 3.2 SDE — 국채금리 확장 모델

국채금리를 추가 입력 변수로 포함한 결과, **최종 예측 정확도 60.00%**(기본 대비 +13.33%p). 하락 구간·단기 조정 구간에서 방향성 예측이 더 안정적으로 이루어졌고, 상승/하락 구분 민감도도 상승.

흥미롭게도 **달러인덱스를 추가한 실험에서는 성능 개선이 제한적**이었음 — 환율 변수보다 금리·채권 시장 요인이 단기 지수 등락에 더 직접적인 영향을 미친다는 점을 시사. 이후 실험은 국채금리 중심으로 진행.

> 전체 데이터: [`results/sde_extended_bondyield_predictions.csv`](../results/sde_extended_bondyield_predictions.csv)

### 3.3 GRU — 초기 모델 (데이터 누수 상태)

동일 입력 특징으로 30일 순차 예측 수행 결과 **86.67%**라는, 금융 시계열 예측 치고는 비정상적으로 높은 정확도가 관측됨.

세부 검토 결과:
- 테스트 구간의 입력 시퀀스가 학습 데이터 정규화 기준과 간접적으로 연결되어 데이터 누수 발생 가능성
- 시퀀스 생성 과정에서 미래 값이 미세하게 포함되는 구조적 오류
- 출력값이 특정 범위로 과도하게 클리핑되며 예측 변동성이 비정상적으로 축소

> 전체 데이터 (참고용, 신뢰 불가): [`results/gru_initial_leakage_predictions.csv`](../results/gru_initial_leakage_predictions.csv)

### 3.4 GRU — 누수 수정 후 최종 모델

수정 사항:
1. 정규화 기준을 "테스트 구간 이전의 훈련 데이터"로 제한
2. 시퀀스 생성 방식을 미래 정보가 한 단계도 유입되지 않도록 전면 재구성

수정 후 동일한 30일 롤링 예측 결과, **최종 정확도 64.29%**로 안정적으로 조정됨. 초기의 비정상적 정확도가 실제 예측력이 아닌 데이터 구성 오류에서 비롯되었음을 확인.

> 전체 데이터: [`results/gru_final_predictions.csv`](../results/gru_final_predictions.csv)

## 4. 논의

- **SDE**: 이론적으로 금융 데이터의 확률적 움직임을 직접 모델링할 수 있다는 장점이 있으나, 입력 변수 선택에 따라 성능 편차가 컸다. 국채금리 단일 변수 포함 시 최고 성능을 기록해, 금리 변화가 단기 방향성에 더 직접적인 영향을 미친다는 해석이 가능하다.
- **GRU**: 데이터 누수 제거 후에도 64% 이상의 안정적인 방향 예측 성능을 보여, RNN 계열 모델이 금융 시장의 단기 움직임을 포착하는 데 강점이 있음을 시사한다. 다만 과거 관측값에 과도하게 의존하는 구조적 특성상, 장기 예측에서는 오차 누적으로 예측력이 급격히 저하될 가능성이 있다.
- 두 모델 모두 완전한 예측력을 확보하지 못했는데, 이는 금융 시계열이 갖는 본질적 비정상성(non-stationarity)과 구조적 변동성이 예측 모델의 절대적 한계로 작용하기 때문으로 해석된다.
- 이 연구의 핵심 의의는 모델 성능 비교 자체보다, **데이터 전처리·변수 선택·구조적 오류(데이터 누수) 점검의 중요성**을 실증적으로 확인했다는 데 있다. 금융 시계열 모델링에서 오차의 상당 부분은 모델 자체가 아니라 데이터 구조에서 비롯된다.

---

## 5. 결론

SDE와 GRU는 서로 다른 원리에 기반하지만, 각각 금융 시계열의 비정형성과 높은 변동성 속에서 일정 수준의 예측력을 확보할 수 있음을 확인했다. SDE는 변수 구성에 따라 성능 편차가 컸고(국채금리 포함 시 최고 성능, 달러인덱스 포함 시 성능 저하), GRU는 데이터 누수 수정 후 약 64%의 안정적인 방향 예측률을 유지했다.

연구 과정에서 데이터 누수와 변수 스케일링 오류를 수정하며 모델 성능이 크게 달라지는 것을 확인했고, 이를 통해 금융 시계열 예측에서는 **모델 선택 못지않게 데이터 처리 과정의 정교함**이 중요함을 재확인했다. 향후 연구에서는 뉴스·심리 지표, 거래량 기반 미시 데이터 등을 포함한 다변량 구조로 확장해 예측 성능 향상을 탐색할 수 있다.
